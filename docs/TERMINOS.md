# Nexus Studio — Condiciones de uso

Actualizado: 17 de noviembre de 2026.

## Qué es Nexus Studio

Nexus Studio es el proyecto personal de escritorio para Windows de Trefot, cuyo código y documentación se publican en [Trefot/Creator-Hunter](https://github.com/Trefot/Creator-Hunter). Permite organizar contenido, consultar métricas de cuentas autorizadas y utilizar herramientas locales para grabaciones, directos y juegos.

El proyecto está destinado al uso personal de su propietario. La integración de TikTok se configura para pruebas con la cuenta añadida como usuario de Sandbox; esta documentación no declara una aprobación de TikTok para producción ni disponibilidad para usuarios externos.

## Cuentas y autorizaciones

Conecta únicamente cuentas propias o cuentas para las que tengas autorización. Cada proveedor determina qué permisos y datos permite consultar. La conexión de TikTok requiere autorización para información básica y estadísticas (`user.info.basic` y `user.info.stats`). El seguimiento opcional de publicaciones también requiere `video.list`; las estadísticas de otras redes pueden exigir permisos adicionales. Las consultas son periódicas con Nexus abierto y pueden reflejar retrasos del proveedor. Las orientaciones de rendimiento dependen de la muestra disponible y no garantizan resultados. La integración actual consulta métricas: no publica vídeos en TikTok ni ofrece recepción de TikTok LIVE.

Puedes interrumpir la conexión desde Nexus y revocar el acceso desde el proveedor. Las autorizaciones pueden caducar. Las funciones que dependen de plataformas externas pueden dejar de estar disponibles si cambian sus API, permisos o condiciones. No se promete disponibilidad permanente ni una exactitud que exceda los datos entregados por cada plataforma.

Conserva privados tus tokens, claves, sesiones y enlaces de control locales. No los publiques en el repositorio, incidencias, capturas o emisiones.

## Datos y archivos

Consulta la [Política de privacidad](PRIVACIDAD.md) para conocer el tratamiento de los datos y las opciones de desconexión y eliminación. El usuario controla sus archivos locales y copias de seguridad. Los datos históricos pueden permanecer en las copias que haya creado.

## Servicios externos y código

El uso de cuentas y servicios externos está sujeto también a las condiciones de sus proveedores. Nexus Studio es un proyecto independiente y no se presenta como producto oficial de TikTok ni de las demás plataformas. Estas condiciones describen el uso de la aplicación; las licencias del código y sus dependencias son las que figuran en el repositorio y sus avisos correspondientes.

## Contacto

El responsable del proyecto es Trefot. Para consultas generales sobre el software utiliza las [incidencias del repositorio](https://github.com/Trefot/Creator-Hunter/issues). Son públicas: no incluyas datos personales, tokens ni documentos privados. Para retirar el acceso de una cuenta utiliza los controles de desconexión de Nexus y los de la plataforma correspondiente.
